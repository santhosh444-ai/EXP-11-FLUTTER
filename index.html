EXPERIMENT 11 – ADD iOS AS A BUILD TARGET

Important: This experiment requires macOS + Xcode for actual iOS building and testing.

Procedure Steps

  1. Check Flutter Setup: Run flutter doctor in the terminal to verify the environment.
  2. Check Available Devices: Run flutter devices to see connected simulators/devices.
  3. Create Project: Generate a new application structure: 
    flutter create ios_app\ncd ios_app
  4. Open in Xcode: Launch the workspace file: open ios/Runner.xcworkspace
  5. Select Target: Choose an active iOS Simulator inside the Xcode interface.
  6. Run Application: Launch using flutter run or directly via the Xcode interface.
  7. Test Application: Comprehensive verification of:
    • UI components
    • Navigation and screen transitions
    • Text fields, buttons, and images
  8. Build Project: Use the Flutter/Xcode workflow for the final iOS distribution package.

Expected Result & Output Screenshot

The Flutter application successfully configures, targets, and renders correctly inside the target simulated screen layout enviornment.
